# Migrações PostgreSQL arquivadas

Essas migrações pertencem ao banco PostgreSQL anterior e não são aplicadas pela
configuração atual do Prisma, que usa `prisma/migrations` exclusivamente para SQLite.

Elas foram preservadas apenas como referência histórica. Não copie esse diretório
para `prisma/migrations` sem adaptar e validar novamente o SQL para o provider usado.
